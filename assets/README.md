# Portfolio assets

This directory holds original, repository-owned visual assets for the portfolio.

- `generated/` — AI-generated images and derived variants
- `project-covers/` — project-specific cover images and diagrams
- `3d/` — 3D source assets and optimized web exports
- `brand/` — approved identity assets

Keep source assets separate from optimized web derivatives where practical. Use only Phosphor for UI icons.
