# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Recruiters, hiring managers, and technical peers evaluating Vaibhav Khurana for data, applied AI, and AI-architecture work. They need a fast, credible path from professional focus to the live systems that demonstrate it.

## Product Purpose

Present a concise professional portfolio where live, verified projects—not generic claims—demonstrate an AI engineer and architect trajectory grounded in data analytics and data science.

## Positioning

The portfolio treats projects as evidence-backed delivery records: only live, approved projects appear, their systems are understandable at a glance, and their documentation stays traceable without exposing internal release metadata to visitors.

## Operating Context

Visitors explore the home page, scan a horizontal live-project rail, use the project library to compare work, and open a project for stakeholder or technical review. Project OS supplies validated manifests that keep project availability and technology coverage current.

## Capabilities and Constraints

- Profile route remains unchanged in this scope.
- Azure and AWS certification may be described generally; exact certificate names are not shown.
- The home page uses the owner-provided portrait at `public/assets/profile/vaibhav-khurana.png`.
- Public projects must be both approved at an exact source revision and live with a verified URL.
- Project-page architecture views must be useful interactive diagrams with no source SHA or generator stamp visible to visitors.
- Public release is automated only after validation, live-deployment evidence, and registry checks pass; paid resources remain separately controlled.

## Brand Commitments

Warm editorial, evidence-first, concise, professional, and structured. Information uses flows, short bullets, tables, and clear labels rather than decorative visuals or unstructured text walls.

## Evidence on Hand

- Live project manifests and approved registry entries.
- Owner-provided professional portrait.
- Existing project architecture assets and stack metadata.

## Product Principles

1. Let verified work lead the narrative.
2. Make technical systems legible to both stakeholders and practitioners.
3. Show only public, live, approved work.
4. Keep the portfolio automatically current through validated project data.

## Accessibility & Inclusion

Keyboard-accessible navigation, controls, horizontally scrollable content, and diagram interactions; reduced-motion support; explanatory labels for technical terms and special values.
